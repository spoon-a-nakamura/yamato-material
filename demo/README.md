**バックエンド無し**で確認するためのデモです。サーバーとの通信は一切行いません。

- 設計書：[`docs/DESIGN_v0.1.md`](docs/DESIGN_v0.1.md)
- 判断ログ：[`docs/DECISIONS.md`](docs/DECISIONS.md)

## いちばん簡単な開き方

`dist-standalone/yamato-webcatalog-demo.html` を**ブラウザにドラッグ＆ドロップ**してください。
1ファイルで完結しているため、インターネット接続もインストールも不要です。
メール添付・USB・共有ドライブでそのまま配れます。

### デモ用パスコード

社内モード（詳細図面・メーカー情報の表示）の切り替えパスコードは `yamato` です。

---

## 開発環境で動かす

```bash
npm install
npm run dev            # http://localhost:3000
```

## ビルド

```bash
npm run typecheck          # 型チェック
npm run build              # Next.js 静的エクスポート → out/（347ページ）
npm run build:standalone   # 単一HTML → dist-standalone/yamato-webcatalog-demo.html
```

`npm run build` の出力（`out/`）は静的ファイルのみです。
Vercel・S3・任意の静的ホスティングにそのまま置けます（提案書 11-2 B案）。

## データ

| 区分 | 件数 | 出典 |
| --- | --- | --- |
| 実データ | 136 SKU | `仕様リスト_食品プラスチック(ボトル).xlsx`（2シート） |
| デモ用の架空データ | 127 SKU | 食品ガラスボトル・酒類・キャップ（規模感の確認用） |
| 誌面ページ | 77 ページ | `00_ページ対応表.csv` |

架空データは画面上に「デモデータ」バッジを表示し、メーカー名も
`（デモ）A硝子` のように架空の名称にしています（実在企業に架空商品を紐付けないため）。

変換スクリプトは `tools/convert.py` → `tools/build_dataset.py`（Python 3 / openpyxl）です。
