  lead="Webサイトは複数の層が重なって動いています。「保守」という言葉が指す範囲は会社によって異なるため、まず層ごとに整理いたします。"
>

<Table def k="38mm" dense>

| 層 | 内容 | 本保守の対象 |
| --- | --- | --- |
| ドメイン・DNS | ドメインの維持、名前解決の設定 | 設定変更の対応（更新手続きは貴社） |
| SSL証明書 | 通信の暗号化 | **対象**（自動更新の設定と更新確認） |
| サーバー／OS | サーバーの稼働、OSのセキュリティ更新 | **対象**（構成により担い手が変わります） |
| ミドルウェア | Webサーバー、アプリケーションの実行環境 | **対象**（バージョン更新と互換性の確認） |
| データベース | 商品データの保存領域 | **対象**（稼働監視、バックアップ） |
| アプリケーション | 本Webカタログのプログラム、管理画面 | **対象**（不具合の修正、脆弱性の対応） |
| コンテンツデータ | 商品情報、画像、図面 | 対象外（貴社にて運用。ただしバックアップの取得は対象） |

</Table>

<KeyPoint>
<strong>「サイトが見られなくなる」「改ざんされる」という事象に関わる層は、すべて保守の対象に含めています。</strong>
</KeyPoint>

</Slide>

| 攻撃の検知・遮断 | クラウド事業者 | 不正アクセスの遮断、通信量の異常検知 |
| アプリケーションの脆弱性対応 | **弊社** | プログラムの修正、ライブラリの更新 |

| 障害時の一次対応・原因切り分け | **弊社** | 状況確認、影響範囲の特定、復旧作業 |
| コンテンツの更新 | 貴社 | 商品情報の登録・修正 |

  </Table>

  <KeyPoint>
  この構成の要点は、<strong>攻撃が集中する深夜や休日の対応が、人手ではなく事業者の自動体制に委ねられる</strong>ことです。攻撃の多くは海外から発生し、日本の業務時間外に集中します。人による監視でこれに追随し続けることは現実的ではありません。
  </KeyPoint>

  title="平常時の運用"
  lead="月額に含まれる、日常的な作業です。"
>

<Table def k="46mm" dense>

| 項目 | 頻度 | 内容 |
| --- | --- | --- |
| セキュリティ更新の適用 | 随時（脆弱性情報の公開に応じて） | ミドルウェア・ライブラリの更新。互換性を検証してから適用いたします。 |
| 稼働監視 | 常時 | サイトの応答を自動監視。停止を検知した場合に通知が届きます。 |
| バックアップの取得 | 日次 | データベースとファイルを取得。7日分を保持いたします。 |
| バックアップからの復旧確認 | 年1回 | **取得できているだけでは復旧できません。** 実際に戻せるかを定期的に確認いたします。 |
| SSL証明書の更新確認 | 更新期日前 | 自動更新の動作確認 |
| 管理画面の動作確認 | 月次 | 一覧表との同期機能が正常に動作しているかの確認 |
| 稼働レポートのご提出 | 四半期ごと | 稼働状況、実施した更新、検知した事象の報告 |

</Table>

<KeyPoint>
<strong>バックアップからの復旧確認</strong>を項目として明記しているのは、ここが実務上もっとも見落とされやすい箇所だからです。バックアップが取得されていても、いざ復旧しようとすると戻せないという事態は起こり得ます。
</KeyPoint>

</Slide>

  variant="center"
>

<Steps row>
  <Step title="検知">
  自動監視による通知／貴社からのご連絡
  </Step>
  <Step title="一次対応（状況確認）">
  ・サイトの応答状況、管理画面の状態を確認<br />
  ・サーバー層かアプリケーション層か、原因の所在を切り分け<br />
  ・影響範囲を特定（閲覧不可／表示崩れ／データ改変 等）
  </Step>
  <Step title="ご報告">
  確認できた事実と、想定される復旧の見通しをご連絡します。<strong>原因が未特定の段階でも、判明している事実をお伝えします。</strong>
  </Step>
  <Step title="復旧対応">
  ・改ざんの場合：該当箇所の特定と除去、侵入経路の封鎖<br />
  ・停止の場合：原因の除去、または直近のバックアップから復旧<br />
  ・攻撃が継続している場合：通信の遮断措置
  </Step>
  <Step title="原因の報告と再発防止">
  何が起きたか、なぜ起きたか、何を対策したかを<strong>書面でご報告</strong>します。
  </Step>
</Steps>
